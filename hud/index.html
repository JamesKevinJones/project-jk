Every session starts as a stranger

A context window has a ceiling. Fill it and the oldest things fall out first, which is usually everything you explained about your own work.

02

So the memory moved out of the model

Every note in the vault is a file on disk. Nothing here is embedded, indexed by a vector database, or held in a window. This is the real graph, drawn live.

03

Structure is what makes it findable

Notes link to each other. Folder indexes map each area. The agent starts at the root index and walks, rather than searching and hoping.

04

A job loads only what it needs

One note per recurring task names the handful of notes that task requires. Watch the vault go dark. That is the whole idea, on real data.

05

And it keeps itself honest

A validator walks the vault the way the agent does at boot and fails loudly on a dead end. The console below is that check, running now.
